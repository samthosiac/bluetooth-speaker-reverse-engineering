# Bluetooth Speaker Reverse Engineering

> Hardware project focused on reverse engineering, PCB inspection, repair and modification of a Bluetooth speaker.

## Overview

This project documents the physical investigation and repair of a Bluetooth speaker, including PCB inspection, LED replacement and planned hardware modification.

## Project Goals

- Inspect and understand the internal hardware
- Identify major PCB components and connections
- Diagnose a hardware issue
- Replace the damaged LED through soldering
- Document the repair process
- Explore a future USB-C charging modification
